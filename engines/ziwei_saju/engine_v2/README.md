# engine_v2 · 자미두수·사주 간명 엔진

이 엔진은 아무 생년월일시를 받아 L0(명식, 명반, 십이장생, 대운, 대한, 세운), L1(구조 판독), L3(두 경로 운 사건과 8절 정량 노출도)을 구조화된 사실(dict)로 낸다. 설계는 `원점재검토_20261111/10_모델명세.md` 판 1.2를 따른다. 명세 항목별 코드 유무는 `50_코드화_현황.md`에 있다. 판정 문장(L4)과 궁별 구절 판독(L2)은 범위 밖이다. 엔진 코드에는 명반 하나의 궁이나 별 값이 없다. 그런 값은 시험의 기대값에만 나온다.

## 실행

```
pip install sxtwl pytest
cd 계산코드
python -m engine_v2 1999-08-04 10:14 M --solar-offset -38      # L0·L1·L3 요약 JSON
python -m engine_v2 1999-08-04 10:14 M --solar-offset -38 --full   # l3.exposure 포함
python -m pytest engine_v2/tests -q
```

선택 인자는 다음과 같다.
- `--tz`: 시계의 UTC 오프셋 시간이다. 기본값은 9다.
- `--sihua nanyang|wangtingzhi`: 대안 사화표를 쓴다.
- `--seun-boundary lichun|seol|jan1`: 세운의 해 경계를 정한다. 기본값은 입춘이다.
- `--zi-rule next_day|same_day`: 23시대 子時를 다음 날로 셀지 정한다.
- `--leap-rule same|next|split15`: 윤달 처리법을 정한다.

세운 경계, 子時, 윤달의 기본값은 모두 가정(미확인)이고, 출력에 그렇게 표시된다.

파이썬에서는 `engine_v2.compute(date, time, male, solar_offset_min, tz, sihua_variant=None, sihua_overrides=None, seun_boundary='lichun')`를 부른다.

## 층별 함수

| 층 | 모듈 | 함수 | 내는 것 |
|---|---|---|---|
| L0 역법 | calendar.py | `resolve` | 양력 일시를 받아 음력(윤달), 시지, 사주 네 기둥(입춘·절입 순간 기준), 앞뒤 節, 가정 표시를 낸다 |
| L0 안성 | chart.py | `build`, `place_stars`, `kong` | 명궁·신궁·오행국, 14주성, 보좌·살·잡성, 밝기, 생년 사화, 공망(순공·절공·정공·방공), 十二長生(`changsheng`), 命主·身主를 낸다 |
| L0 운 기간 | luck.py | `daewoon`, `daehan`, `seun_period`, `seun_years_between` | 대운(절기 정밀, 음양 순역, 시작 일시), 대한 열둘(국수, 순역, 만 나이 생일 경계), 세운 기간(경계 설정)을 낸다 |
| L1 | structure.py | `analyze` 외 단계별 함수 | 명세 3절 13단계를 낸다. 아래 L1 목록을 본다 |
| L3 | fortune.py | `path_daehan`, `path_daewoon`, `contrast`, `ji_readings`, `overlaps`, `exposure`, `overlap_years` | 명세 4절의 1~10번과 8절의 1·4번을 낸다. 아래 L3 목록을 본다 |
| 표 | tables.py, data/ | `Sihua`, `Brightness` | 십간사화표와 밝기표를 한 벌씩 읽는다 |

L1이 내는 것은 다음과 같다.
- 공궁과 쌍(성립·차단). 차단에는 공망 종류와 확인 여부를 붙이고, 절공과 순공이 함께일 때만 확인이다. 방공은 쓰지 않는다.
- 제화 지점, 밝기 지도, 본명 삼방사정 분포(밝기 포함), 록의 자리.
- 기본격 성립 여부.
- 궁 단위 수용성. 못 받는 주성 수만 내고 판정어는 붙이지 않는다.
- 변곡점 넷, 협(`jia`).

L3이 내는 것은 다음과 같다.
- 사화 표시. 성립 쌍 복사는 하나로 센다.
- 세 틀 집계: 대한명궁, 대한 삼방사정 네 궁(공궁 대궁의 화기 포함), 본명 삼방사정.
- R22 중첩과 화기 중첩이 선 천간의 수(틀별 `overlap_k`와 `overlap_list`, 천간 단위 k/10. 록·권·과는 `overlap_years.by_hua`).
- 노출도(`l3.exposure`). 틀 셋(대한명궁, 대한삼방, 본명삼방)마다 록·권·과·기 각각 `k`(분모 `of`=10)와 그 천간·별 목록 `list`. `natal`은 본명 삼방사정만, `daehan`은 대한 열둘. 틀에 드는지는 `frames`를 그대로 쓴다(공궁 차성, R17 확장은 화기에만). 수용성은 `path_daehan[].receptivity`의 `none_count`(m)와 `main_total`(n)이다.
- 두 판독 틀. 구조 통변은 자리로 읽고, 나눠 가짐과 공망과 만난 중첩의 길을 적는다. 대한 삼방 비춤은 쌍으로 세고, 중첩을 대흉으로 적는다. 두 틀이 다르면 갈림이다.
- 록과 권의 진입.
- 같은 천간의 해. R13 단서는 대한 삼방에 들고 생년 화기와 겹칠 때 붙인다.
- 제화 사건(대운 교체로 화기가 줄어듦, 차단 쌍 보내는 궁의 화기와 해공 조건부)과 육길성 사건.
- 두 경로 대조. 일치와 불일치만 쓰고, 불일치는 갈림으로 둔다.

사화는 생년, 사주 대운 천간, 세운 천간에서만 낸다. 궁간사화 함수는 없다. 서열은 `fortune.ORDER`의 하나(대운이 세운보다 큼)뿐이고, 숫자 가중치는 없다. 화기 중첩의 길흉은 `fortune.FRAME_LABELS`에 틀별 표지로만 둔다.

## 데이터 출처

| 표 | 파일 | 기본값과 출처 | 바꿀 수 있는 것 |
|---|---|---|---|
| 십간사화 | data/sihua.json | 기본값은 자미두수전집 권3 명경각본 원판이다(庚日武陰同, 壬梁紫左武). 명세 6절 표와 같다 | `庚.과`, `庚.기`, `壬.과`를 바꿀 수 있다. 대안 `nanyang`은 전서 남양당본이다(庚日武同相, 壬梁紫府武). 대안 `wangtingzhi`는 왕정지 표다(庚 陽武府同, 壬 천부) |
| 밝기 | data/brightness.json | 칸마다 출처 층이 붙는다. 첫째 층은 `자붕이`로, 자붕이가 이 명반에 적은 값이다(A 요약표 B 번호). 둘째 층은 `전서권3성론`으로, 전서 권3 별별 해설의 명문이다. 그 밖의 칸은 None(미확인)이다 | 등급은 셋으로 나눈다. 廟·旺·得은 묘왕(得은 2621), 平은 평, 不·陷은 함이다. 利와 None은 미확인이다. 전서 밝기표를 앞에서부터 읽은 값, ADOPT, REC는 쓰지 않는다 |

안성 자리 계산은 byeonseong/anxing.chart_any와 zaxing.place에서 옮겼다. 옮기면서 고친 것은 다섯이다.
- 천재·천수의 卯년 고정을 없앴다.
- yun의 1999년 고정과 절기 표를 없앴다.
- guard의 생일에 묶인 상수를 없앴다.
- 양력·윤달 변환을 더했다.
- 命主·身主·蜚廉·十二長生을 더했다.

## 시험

시험 파일은 넷이다(166건).
- `tests/test_regression.py`: L0·L1 단언, 명세 3절 검산값을 본다.
- `tests/test_external_tool.py`: 외부 도구 명반과 별 자리를 대조한다.
- `tests/test_regression_luck.py`: 운 단언, 갈림 시험(戊 천기 화기, 2018 화록과 쌍 화기, 己의 酉 중첩), 노출도 검산값을 본다.
- `tests/test_generality.py`: 다른 생년월일 여덟 건(재현 A, B, C 포함)의 불변식과 노출도 범위, 세운 경계 설정, 명반 상수 정적 검사를 본다.

시험마다 docstring에 B 번호가 있다. 대상 명반은 양력 1999-08-04, 남, 시계 10:14, 진태양시 보정 -38분이다(guard.py BIRTH와 같다).

명반 상수 검사(`test_no_chart_constants_in_conditions`)는 엔진 파일의 조건문을 AST로 훑는다. if, while, 조건식, 비교, 컴프리헨션 조건에 지지 한 글자나 주성·보좌·살 이름 문자열이 있으면 실패한다.

## 알려진 한계

- 밝기가 None인 칸이 많다(무곡 子, 거문 卯, 염정 申, 천동 亥, 보좌·잡성 대부분). 그 궁의 밝기 구분은 `미확인`이다.
- 자붕이 층 밝기는 B 표의 진술로 채웠다. 그래서 밝기 단언은 별 자리와 표 조회를 검사하고, 밝기 값을 독립적으로 재현하지는 않는다.
- 4절 7번의 인용("대한명궁으로는 길흉을 점치기가 힘들다")은 특정 기간에 붙는 문장이다. 그래서 엔진은 수만 내고 인용은 L2·L4로 넘긴다.
- 시간대는 하나의 고정 오프셋이다. 한국의 1950~60년대 UTC+8:30과 1987~88년 서머타임은 호출자가 맞춘다.
- 화성·영성 자리는 성별에 따라 순역을 바꾸지 않는다. 蜚廉 표의 출처는 확인하지 못했다.
- 기본격은 살파랑만 본다.
