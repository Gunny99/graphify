# 사주 판정 가운데 표에 넣지 못한 것

대상 명식: 남 1999-08-04 10:14 巳時, 己卯 辛未 戊子 丁巳. 월령 격은 子平真詮으로 SJ20~SJ26에 넣었다(77_월령격_판독.md). 원문 쪽은 三命通會 kanripo 전사(01_raw/三命通會_kanripo전문/NNN.txt, NNN은 권)다.

| 판정 | 이유 |
|---|---|
| 용신·억부·조후(후대 해석) | 滴天髓 등 후대 책이 읽기 범위 밖이다. 三命通會 안에 戊日 夏生 조후 구절(卷四 論戊己)을 찾았으나 戊子日 未月에 걸리는 문장은 004:153-158(SJ17, SJ18)뿐이었다 |
| 咸池(년지·월지 기준 亥卯未의 咸池 子가 일지에 있음) | 002:1884 제목 주에 "天干納音於地同類方是"라는 조건이 있다. 咸池 子는 水이고 년주 己卯의 납음은 城頭土, 월주 辛未는 路旁土라 같은 종류가 아니다. 조건이 서지 않아 넣지 않았다. 설명서 스레드의 합치표 13번은 이 조건 없이 합치로 적었다 |
| 將星(년지 卯 자신) | 002:1860-1863에서 "吉星相扶 貴煞加臨"일 때 吉이라는 조건이 붙는데 어느 별이 이 사주에 해당하는지 정할 기준이 원문에 없다 |
| 空亡(일주 戊子의 空亡은 午未, 월지 未가 걸림)의 生旺·死絶·合·受殃 가지 | 003:1080-1084. 生旺·死絶은 未가 土의 衰(火 기준) 또는 養(水 기준)이라 어느 기준으로도 서지 않는다. 「支干與天中相合」은 未의 六合 午가 없고, 「為我所尅」은 생년 납음 城頭土와 空亡 기둥 辛未 路傍土가 같은 土라 서지 않는다. 併 가지 가운데 華蓋併만 SJ29로 넣었다(咸池六害 읽기와 신살별 기준 차이가 미확인 조건) |
| 天乙貴人(戊는 丑未, 월지 未) | 003:424-425에서 戊子日은 丑을 기뻐한다고 하여 未가 걸리는지 갈린다. 결과도 길흉 방향 외에 낱말이 없다 |
| 太極貴(戊는 辰戌丑未, 월지 未) | 003:656-658의 결과 문장이 "福氣貴神扶"라는 조건 아래 있어 조건을 옮길 수 없었다 |
| 傷官格의 結(傷盡 多藝多能, 傷官見官 禍患百端 따위, 005:1368-1470) | 傷官格은 월령이 傷官일 때의 격이다(005:1376). 이 사주는 월지가 未이고 월간 辛이 투출했을 뿐이라 형태가 서지 않는다. "月帶傷官 兄弟不完"(SJ16)만 넣었다 |
| 월주·일주·시주를 주체로 한 납음 구절(霹靂火의 「砂中丁巳有風 己卯有雷 得泉助之亦主貴顯」, 路傍土의 「辛未見戊子印貴朝陽」) | 001:836-842의 「…生人 月日時胎 別見他位納音」 틀에서 납음 구절의 주체는 생년 납음이다. 이 명식의 주체는 년주 己卯 城頭土뿐이라 그 구절만 SJ27, SJ28로 넣었다. 城頭土 구절의 木·水·金 조건은 해당 납음이 없어 서지 않고, 시주 砂中土는 언급이 없다 |
| 충과 합(10절 5번의 충과 육합) | 사주 안에 충과 육합이 없다(子卯 刑과 子未 害만 있어 SJ14, SJ15로 넣었다). 대운·세운의 충합 판정은 삼명통회의 해당 구절을 찾지 못했다 |
