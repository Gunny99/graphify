# 骨髓賦 「發不主財」 주: 전서와 전집 원판 대조 (2026-10-21)

ID: 전집-5-批注骨髓賦-0001
서지: 飛星策天紫微斗數全集 卷5 批注骨髓賦, 1870 明經閣板(규장각 GI40495_00), 권5 스캔 008 오른쪽 면(합본 PDF 154쪽). 바탕 텍스트 01_raw/자미두수전집_紫微之源/전6권_947548430.txt 3571~3572행.
상태: 교감완료(원판 그림 300ppi 판독, 이 조항만)

원판(전집): 發不住財祿主躔於弱地 / 如化祿陷於劫空是也又或子午申酉宮雖化權祿無用亦主孤貧
전서(남양당본 卷2 斗数骨隨賦註觧, 전서남양당-2-斗数骨隨賦註觧-0018): 發不主財祿，主緾于弱地。假如化禄陥于刼空是也。又或子午申酉宫，雖化禄無用，亦主孤貧。
紫微之源 텍스트: 发不主财，禄主躔于弱地。假如化禄陷于劫空是也，又或子午申酉宫虽化权禄无用亦主孤贫。

직역: 발하여도 재물을 머물게 못하니 녹이 약한 땅에 들었기 때문이다. 화록이 겁공에 빠진 경우요, 또 子·午·申·酉 궁에서는 화권·화록이 되어도 쓸모없고 외롭고 가난하다.
차이: 전집 원판은 「化權祿」(권까지 무력), 전서는 「化禄」만. 표제 첫 구는 전집 「住」, 전서 「主」. 紫微之源은 「主」로 적어 원판과 다르다(紫微之源 오기 1건).
매칭 요소: 子午申酉 궁의 화권·화록. 원국 적용 여부는 설명서 판정(명·신궁 대상이라 원국에 안 건다는 기존 판정)을 따른다.
쓰임: 「雖化禄無用」 원판 대조 대기 항목 종결. 판정 반영은 설명서 스레드 몫.

원판: 鈴武廉陀夫婦離 / 紫微男主妻賢女主夫榮內助旺夫有刃宜招夫長 / 武曲男主妻性急女主夫貴加四煞生離剋害 / 天府男主妻小聰明女主夫長加四殺主剋婚遲
紫微之源: 紫府同梁左右和，禄文日月两相宜，贪羊七杀皆三度，铃武廉陀夫妇离 / 武曲 男主妻性急，女主夫贵加四煞生离克害 / 天府 男主妻小聪明，女主夫长，加四杀主克婚迟.
차이: 세 조목 글자 일치(간번체만 다름).
직역: 영성·무곡·염정·타라가 부처에 있으면 부부가 떨어진다. 무곡은 남명이면 아내 성정이 급하고, 사살이 더하면 생이별하거나 극해한다. 천부는 남명이면 아내가 작고 총명하며, 사살이 더하면 극하고 혼인이 늦다.
