# ziwei_saju 라이브러리 (공개분)

자미두수·사주 간명 엔진이 근거로 삼는 원전 자료와 근거 색인이다. 개인 명반 자료는 올리지 않는다.

- 올린 것: 저작권이 소멸한 고전의 원문·전사(01_raw), 우리가 만든 색인·근거표(00_INDEX, 02_primary, 03_support, 04_MAP, STATE). 이름은 중립 이름으로 바꿨다.
- 올리지 않은 것: 현대 저작과 타인 글 전문(달밭, 王亭之, 陸斌兆, 현묘, 카페 글 등), 현대 주석·판본이 섞인 자료, 자붕이 원문 인용 색인, PDF·이미지, 봉인 예측과 홀드아웃. 올리지 않은 01_raw 파일은 EXCLUDED_PLACEHOLDERS.tsv에 경로·사유·크기·sha256만 둔다.
- MANIFEST.sha256: 올린 파일 전체의 sha256. `cd library/ziwei_saju && sha256sum -c MANIFEST.sha256`로 확인한다.
- 02_primary/전서_확정본/: 전서 확정본 = 남양당본 기준 교감 확정본(2026-11-25). 02_primary/전집_확정본/: 전집 확정본 = 明經閣 1870 원판 기준 전사 확정본(권1~6, 교기.tsv에 판각오류·판독불가 기록). 판독불가는 □/(개) 표시.
- 근거 구절은 경로와 행 범위, 내용 해시(sha256)로 가리킨다. 원전은 미교정 OCR이 많으므로 판본 차이는 그대로 둔다.
